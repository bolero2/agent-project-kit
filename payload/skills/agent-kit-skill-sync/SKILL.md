# Agent Kit Skill Sync

사용자가 스킬 생성·수정·삭제를 요청하면 다음 절차를 따른다.

1. `.agent-project-kit/CONTEXT.md`의 `선언된 Agent 도구` 목록을 읽는다. 목록이 비어 있거나
   오래되었으면 사용자에게 확인해 갱신한다.
2. 스킬 본문은 한 벌만 작성하고, 선언된 각 도구의 공식 스킬 경로에 동일한 내용으로 반영한다.
   - Claude Code: `.claude/skills/<name>/SKILL.md`
   - Codex: `.agents/skills/<name>/SKILL.md`
   - 그 외 도구: 그 도구의 공식 규약을 문서로 확인한 뒤 반영한다. 규약을 확인할 수 없으면
     추측하지 말고 사용자에게 묻는다.
3. 수정·삭제도 같은 요청 안에서 모든 도구 경로에 반영하고, 반영 후 사본 간 diff가 0인지 확인한다.
4. 검증: 실행 가능한 도구에서 스킬을 실제 호출해 동일한 결과가 나오는지 확인한다. 현재 세션에서
   실행할 수 없는 도구는 그 범위를 미검증으로 보고한다. 검증 중 만든 산출물은 사용자가 보존을
   요청하지 않는 한 삭제한다.
5. 스킬 이름에 설치된 `agent-kit-` namespace를 쓰지 않는다. 스킬을 commit할 공유 자산으로 둘지
   로컬 전용으로 둘지 사용자에게 확인하고, 결정을 CONTEXT의 프로젝트 로컬 메모에 기록한다.

`agent-kit-*` 하네스 스킬 자체는 이 절차의 대상이 아니다. 킷 재설치로만 갱신한다.
