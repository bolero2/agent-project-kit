- 동작: 동기화 대상(`.claude/` — 복사 모드와 동일한 파일 목록 함수 공유)은 `cmp`로 내용
  비교 후 다른 파일만 unified diff(`-` = 대상 현재 / `+` = 킷 버전) 표시. 프로젝트 소유
  파일(CLAUDE.md, .gitignore, docs/change-log/README.md)은 채워지며 달라지는 게 정상이므로
  존재만 확인. **아무것도 수정하지 않음.** 차이/누락 있으면 exit 1, 완전 동일이면 exit 0.
- 실측 테스트(킷 루트에서 실행, 전부 통과):
  ```bash
  TARGET=$(mktemp -d) && git -C "$TARGET" init -q && ./bootstrap.sh "$TARGET" > /dev/null
  ./bootstrap.sh --diff "$TARGET"; echo $?    # 동기화 4파일 "동일" + 소유 3파일 "있음" → 0
  echo '{}' > "$TARGET/.claude/settings.json"
  ./bootstrap.sh --diff "$TARGET"; echo $?    # settings.json "다름" + unified diff → 1
  ./bootstrap.sh --diff "$(mktemp -d)"; echo $?  # 전부 "없음" 7건 → 1
  ./bootstrap.sh --diff; echo $?              # 사용법 출력 → 1
  rm -rf "$TARGET"
  ```
  검증 앵커: 깨끗한 대상 = "동일" 4 + "있음" 3, exit 0. 변조 시 "다름" 1, exit 1.
