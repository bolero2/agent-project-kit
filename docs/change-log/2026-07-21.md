## [ADD] bootstrap.sh — 검증된 복사 스크립트

- 근거: 기존 문서의 복사 명령이 `~/claude-project-kit` 경로를 전제하나 해당 경로는 실존하지
  않음(실제 체크아웃: `~/main/github/claude-project-kit`) → 문서대로 실행하면 실패.
- 조치: 스크립트가 자기 위치(`BASH_SOURCE`) 기준으로 복사 — 체크아웃 경로 무관.
  no-clobber(기존 파일 절대 덮어쓰지 않음), 멱등, git 아니면 경고, 자기 자신 대상 거부.
- 실측 테스트(킷 루트에서 아래 그대로 실행, 전부 통과):
  ```bash
  TARGET=$(mktemp -d) && git -C "$TARGET" init -q && ./bootstrap.sh "$TARGET"  # "생성:" 7줄
  find "$TARGET" -type f -not -path '*/.git/*' | wc -l                         # → 7
  ./bootstrap.sh "$TARGET"       # 재실행: 전부 "건너뜀(이미 존재)" 7줄 — 멱등성
  ./bootstrap.sh                 # 인자 없음: 사용법 출력, exit 1
  ./bootstrap.sh /no/such/dir    # 없는 경로: 오류, exit 1
  ./bootstrap.sh .               # 킷 자신: 거부, exit 1
  rm -rf "$TARGET"
  ```
  검증 앵커: 신규 대상 기준 생성 파일 정확히 7개 — `CLAUDE.md`, `.gitignore`,
  `.claude/agents/commit-push.md`, `.claude/settings.json`,
  `.claude/skills/_template/SKILL.template.md`, `.claude/skills/claude-md-init/SKILL.md`,
  `docs/change-log/README.md`. 킷 내부 파일(README 등)은 복사되지 않아야 함.
