  ① 허용 — reserved/common 예약 경로 검사에서 런타임 부산물(`__pycache__`/*.pyc,
  `.DS_Store`, 잔여 `<파일>.lock`)을 무해한 것으로 제외(`is_runtime_byproduct`).

  uninstall이 중단됨(테스트로 재현·확인).
  ③ 예방 — 모든 python 훅 호출에 `-B` 추가(provider hook JSON 2종, Git hook 셸, dispatcher의
