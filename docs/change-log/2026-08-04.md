## [ADD] developer 승인 게이트 오버라이드 + agent-kit-update 스킬 (kit 1.3.0, schema v4)

### developer Agent — commit/PR 승인 게이트 오버라이드

- 게이트 상태를 CONTEXT 로컬 메모(`commit/PR 승인 게이트`, 기본 활성)로 관리한다.
- "이번에는 승인 없이 그냥 해" → 해당 티켓에만 생략, CONTEXT 불변(다음 티켓부터 다시 활성).
- "앞으로 계속 알아서 해" → CONTEXT를 `해제 (사용자 지시, <날짜>)`로 갱신, 이후 세션에도 적용.
  다시 켜라는 지시로 복원. 모호하면("알아서 해"만) 이번만인지 계속인지 질문.
- 게이트 생략 시에도 나머지 Git 규칙(스킬 우선, 잘게 커밋, force-push 금지, merge 금지,
  Jira 번호 금지, QA 선행)은 유지.

### 킷 업데이트 관리 — agent-kit-update 스킬 (schema v3→v4)

- 배경: 킷을 여러 프로젝트에서 사용 중이라 업데이트 전파 경로가 필요. copy & paste는
  manifest 없는 복사본을 만들어 guard·doctor·uninstall 소유권 판정을 깨뜨리므로 금지 명문화.
- 수동 경로(기존): 킷 저장소 `git pull --ff-only` + 각 프로젝트 재설치. 재설치는 킷 소유
  파일만 교체하고 tracked 문서·CONTEXT/HANDOFF 보존, 구 schema 자동 업그레이드.
- 자동 경로(신규): `agent-kit-update` 스킬 — 하루 1회(CONTEXT `킷 업데이트 마지막 확인`
  날짜로 제어) manifest의 kit_version과 GitHub origin/master의 KIT_VERSION을 비교하고,
  차이가 있으면 **사용자 승인 후에만** pull + 재설치 + doctor 수행. 네트워크 불가 시 건너뛰고
  보고. 킷 저장소 경로는 CONTEXT 메모(`킷 저장소 경로`)에 기억, 없으면 질문(필요 시 public
  repo clone 안내).
- 어댑터(CLAUDE.local.md / AGENTS.override.md)에 "세션 첫 실질 작업 전 하루 1회 확인" 지시
  추가 — 지침 기반 자동이며 적용은 항상 승인 게이트를 거친다.
- CONTEXT 로컬 메모 필드 추가: `commit/PR 승인 게이트`, `킷 저장소 경로`,
  `킷 업데이트 마지막 확인`.
- schema v4: SKILLS에 `update` 추가 동결. `KIT_VERSION` 1.2.0 → 1.3.0.

  밖 — 수동 smoke test 대상.
- 어댑터의 세션 시작 자동 확인은 지침 기반이라 모델이 건너뛸 수 있다(handoff 자동 발견과
